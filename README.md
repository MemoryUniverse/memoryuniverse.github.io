# memoryuniverse.github.io

The public site, served by GitHub Pages.

| Path | What it is |
|---|---|
| `/landing/` | The landing page |
| `/` | Redirects to `/landing/` |

Static, with no build step: edit the files, push, and Pages redeploys.
`.nojekyll` stops Pages reinterpreting anything.

Docs and other sections can be added as sibling folders.

Part of [Memory Universe](https://github.com/MemoryUniverse).
